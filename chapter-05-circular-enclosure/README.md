# Chapter 5 — Circular enclosure

The common image-profile processing is in [densityheight.m](../shared/densityheight.m). The same starting routine was used with changes to the measurement window and other settings for each configuration. A narrow column window can be supplied where a local vertical profile is required.

Supply coordinates and timestamps belonging to the selected images. The circular geometry does not follow from normalising an image, and timings from other configurations should not be reused without checking the record.

The exact circular area and volume relations, model-profile comparisons, circular-crossflow mean fit and density-evolution checks are not implemented in the six files supplied here. Their inclusion status remains recorded in the [coverage checklist](../SCRIPT_CHECKLIST.md).
