## Workflows to include

These are workflow groups, not a required number of separate files. Suggested names can be replaced by your actual filenames.

## S1 — Shared processing, plotting and export helpers

**Suggested or known candidate name:** `Keep existing helper names`.

Supply helper functions needed for file ordering, timestamp reading, smoothing, normalisation, reviewed selections, plotting and table export. Include only helpers actually called.

| Item | Description |
| --- | --- |
| Inputs | Inputs passed by chapter scripts. |
| Outputs | Reusable functions that allow the chapter entry points to run. |
| Settings to explain | Working directory/path setup, consistent units and normalisation definitions. A helper embedded in a master script needs no duplicate copy. |

## S2 — Source and experimental parameter calculations

**Suggested or known candidate name:** `source_parameters.m or equivalent worksheet`.

Calculate any Reynolds numbers, reduced-gravity/source fluxes, momentum lengths or effective-transport quantities generated by code for the thesis tables.

| Item | Description |
| --- | --- |
| Inputs | Q, nozzle size, viscosity, measured densities and enclosure dimensions. |
| Outputs | Parameter tables and nondimensional groups. |
| Settings to explain | Radius-based Re_p, per-nozzle versus total flow and top-hat/Gaussian or velocity-profile conventions. If calculated in a worksheet or directly in the thesis, record that instead of writing new code. |

## When adding the code

Replace the candidate filename with the actual entry point, give a run command and list the required software/helpers. State the version or test status only when known. Record coverage in [SCRIPT_CHECKLIST.md](../SCRIPT_CHECKLIST.md); the same script can cover more than one entry.
